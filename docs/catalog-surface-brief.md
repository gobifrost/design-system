# Catalog surface brief

## Job

Help a Bifrost engineer or designer orient quickly, inspect real behavior, and copy a reliable starting layer into an existing application.

## Direction

**Chromatic Rail** translates the website's dark technical field into a product workbench. A thin vertical spectrum seam locates the persistent rail. The main field is near-black and typographic; cyan marks action and current location. The catalog stays flat and measured so dense specimens remain the subject.

Approved concept: `.impeccable/mocks/bifrost-field-guide.png`.

## Surface anatomy

| Region | Contract |
| --- | --- |
| Rail | Native Bifrost mark, five icon-led destinations, theme switch, version state, bridge seam |
| Field guide | One decisive thesis, live component rows, live density control, source install command |
| Foundations | Native assets, palette, typography, theme/density rules, motion specimen |
| Workbench | Nine component families, runnable states, per-family usage and property guidance |
| Patterns | Operational and client-facing compositions using one identity at different rhythms |
| Start building | Source registry path, assembly sequence, accessibility and adaptation contracts |

Desktop keeps the rail and guide column stable while the center field scrolls. Mobile transposes the rail into an accessible drawer and stacks actions/specimens without horizontal page overflow.

## Memorable moment

The spectrum seam and route settle make the system feel connected to the Bifrost bridge without filling surfaces with gradient decoration.

## Content and behavior constraints

- Use only local illustrative data; do not imply real customer metrics.
- Keep operational examples scan-first and client examples explanation-first.
- Keep every interactive specimen keyboard-operable and programmatically named.
- Theme and density controls change real runtime state.
- Motion must remain crisp, visible, bounded, and fully removable.
